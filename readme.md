# BMS 模拟器 使用说明

> 电动汽车 BMS 模拟器（Web 版），对齐 GB/T 27930-2023 A 类系统，支持国标 / FAST（大电流）/ 自适应三种模式，可接真实 CAN 盒与充电桩联调。
---

## 1. 运行

### 1.1 运行打包后的 exe

```
BMS_SIMULATOR/BMS_SIMULATOR.exe
```

双击即可（onedir 模式，整个 `BMS_SIMULATOR` 文件夹要一起拷走）。

---

## 2. 界面使用

界面分三个 Tab：**BMS 参数设置** / **充电记录** / **CAN 报文**。顶部常驻 CAN 连接区和状态栏。

### 2.1 连接 CAN

1. **设备类型**：`USBCAN-E-U` / `USBCAN-2E-U` / `USBCAN-4E-U` / `USBCAN-8E-U`（周立功）、`CANalyst-II`（创芯）、`Mock`（无硬件模拟）
2. **通道**、**波特率**（默认 250000）
3. 点「连接」

连接成功后顶部显示「已连接」。**连上盒子会自动清空数据库**，本次报文从 0 开始计数。

### 2.2 选模式、启动充电

1. **模式下拉**选 `gb`（国标）/ `fast`（大电流）/ `adaptive`（自适应）
   - ⚠️ 模式**不热切换**：只能在「等待CHM报文」或「已停止」时切换，充电流程中途切会被拒绝
2. 点「启动充电」（会先复位 CAN，再进入握手流程）
3. 可勾选**自动启动**：空闲态收到充电机的 CHM 报文时自动开始充电流程

状态机状态在状态栏实时显示：等待CHM → 握手 → 辨识 → 参数配置 → 充电中 → 充电完成 / 错误。

### 2.3 BMS 参数设置

从协议定义动态生成各报文的参数表单（BHM / BRM / BCP / BRO / BCL / BCS / BSM / BMV / BMT / BSP / BST / BSD / BEM）。

- 改完点「应用参数」生效
- **电流类字段只填正值**（例如填 `180`），后端按「充电电流为负」自动取负后再编码，无需手填负号
- 报文周期、FAST 填充选项等也在对应报文的表单里

### 2.4 CAN 报文

实时报文流，TX / RX 分色显示。

| 功能 | 说明 |
|------|------|
| **展开解析** | 点击报文行，展开数据域字段（`字段名=值`） |
| **多帧报文** | TP 报文先显示逐帧分帧（RTS + DT，带数据），再显示一条「`XXX(完整)`」（只显示帧头 + 字段解析，不重复数据） |
| **分页** | 每页 1000 / 5000 / 10000 条（默认 5000）；「首页」= 暂停 + 跳第 1 页 |
| **暂停滚动** | 勾选后画面冻结，方便查看 |
| **导出** | 导出全部报文为 CSV（含解析列，UTF-8 BOM，Excel 直接打开） |
| **清空** | 清空历史报文 |

> 高频报文（真桩能量传输阶段约 40 帧/秒）采用定时批量刷新（800ms），画面不会卡顿。

## 3. 三种模式

| 模式 | 电流规则 | 特点 |
|------|----------|------|
| **国标** | offset = -400，无符号 | GB/T 27930 标准流程 |
| **FAST** | 无偏移，有符号（负数 2 的补码） | 大电流协议；CRM 带 `FAST` 标识；BRM 按选项填充 `FAST`/`EE` |
| **自适应** | offset 随 CFC 下发值变化 | 充电机发 CFC 下发偏移量，BMS 回 BFC；前端只设枪数量 |

**FAST 补充**：收到 CRM 首字节 `AA` 会回退国标编码、`EE` 确认大电流；BRM 可按四个选项填充标识（无 / FAST / EE / FAST+EE）。

**自适应补充**：CFC/BFC 为私有协议（`0x1830F456` / `0x183156F4`，250ms 周期）；枪数量不一致时 BFC 应答 `01`，不主动停止。

## 6. 常见问题

**Q：启动时报「加载 ControlCAN.dll 失败」？**
A：`ControlCAN.dll` 必须和 exe 放在同一级目录（开发时放项目根）。确认 DLL 位数与程序一致（本项目为 64 位）。

**Q：CAN 盒拔掉后程序没反应？**
A：已内置掉线检测（约 500ms 周期），拔线会提示「CAN 设备已断开（掉线）」并自动停止充电流程。

**Q：连上盒子后历史报文没了？**
A：这是有意设计——连接时清空数据库，避免翻页时总数突变。

**Q：电流填 180 还是 -180？**
A：填 `180`（正值）。后端统一按充电方向取负，三种模式都一样。

**Q：FAST 模式解析出来的电流不对？**
A：确认模式选的是 `fast`。解析和编码共用同一套模式偏移规则，模式对就不会错。

**Q：为什么只能在同一网段/本机访问？**
A：服务监听 `0.0.0.0`，局域网内可用 `http://<本机IP>:<实际端口>` 访问，实际端口见启动日志（默认从 8001 起，被占用时自动顺延）。如需外网需自行放行防火墙。
